An AI-powered medical image analysis system designed to detect pneumonia from chest X-ray images while providing explanations for model predictions.

Key Features

- Five-model deep-learning ensemble
- Chest X-ray image classification
- Grad-CAM-based visual explanations
- Real-time prediction and inference
- Interactive dashboard and prediction history
- Automated PDF report generation
- Image quality validation
